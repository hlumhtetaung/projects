# **Airport Database**



**Attributes**

* airplane
* registration number
* model



* airport
* model number
* capacity
* weight



* technicians
* name
* SSN
* address
* phone number
* salary



* Traffic controllers
* medical examination
* date of most recent examination



* Union
* Union membership number
* employee's social security number



* airworthy tests
* FAA test number
* name
* maximum possible score



* Testing event
* technician SSN (probably)
* date
* hours spent on test
* score received from the test



**Relations**

* one airport accommodates a number of airplane models
* A number of technicians work at the airport
* Each technician is an expert on one or more plane models
* Traffic controllers must have annual medical examination
* All airport employees belong to a union
* The airport has several tests
* FAA requires the airport to keep track of each time a given airplane is tested by a given technician using a given test
