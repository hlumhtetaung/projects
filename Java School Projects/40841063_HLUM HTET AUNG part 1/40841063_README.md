**Objects approach (for clean coding)**

**Main**

Main file only include matrixGeneration method call from MatrixGeneration class.



**MatrixGeneration**

Matrix generation class is for generating numbers in rows and columns. Column count starts from 1, so the top will always start with odd random numbers.



**Average**

Average class is for finding row and column averages from the matrix.



**SecondLargestAverage**

This class is for finding second largest average value and index for both rows and columns from average array from the class above. The solution I used -

* Use Arrays to sort the array and copy it into another variable.
* Use cloned array to find the first different number starting from the last. (To eliminate duplicated highest values)
* After obtaining the value, find that value in the original unsorted array for the index.



**Transform**

This is for transforming matrix numbers into -1, 0, and 1 according to the higher or lower than row and column averages.
